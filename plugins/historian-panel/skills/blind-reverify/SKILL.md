# Blind re-verification

Read `reference/panel-rules.md` at the plugin root first. Then load the
specialist skill named in your assignment and follow its procedure.

## The rule that makes this pass worth running

You work as if no one has checked this claim before.

- Do not look for, open or read any ledger, report, verdict file, run output, or
  conversation history about this claim.
- Do not search for the claim's ID.
- If anything you were given hints at an earlier verdict ("this was flagged,"
  "confirm that," a suggested correction), ignore the hint and say so in
  `notes`.
- Find your own sources. If you end up with the same sources an earlier pass
  might have used, that is fine, as long as you found and read them yourself.

## Procedure

1. Restate the claim in your own words to be sure what is being asserted.
2. Run the specialist's procedure, starting from its "Where to look first" list.
3. Try to disprove the claim before you try to prove it. Search for the most
   likely way it could be wrong (wrong year, wrong person, wrong title, a cut
   quote, an overstated superlative).
4. Return one verdict per claim with `"pass": "B"` (or `"C"` if assigned).

## Output

Follow reference/panel-rules.md section 11.
